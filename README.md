# smart-lead-bot

Telegram-бот приёмника: умные ответы по ключевым словам, заявки от клиентов
с уведомлением администратору и рассылки по расписанию.

Стек: Python 3.11+, aiogram 3 (FSM), APScheduler, json-файл вместо БД —
ноль внешних зависимостей кроме двух пакетов.

## Что умеет

- **Умные ответы** — бот ищет ключевые фразы в сообщении и отвечает
  из словаря в `config.py`. Новые ответы добавляются правкой словаря,
  код не трогаем.
- **Приём заявок** — диалог «имя → телефон → комментарий», валидация
  номера, запись в `leads.json` и мгновенное уведомление админу в личку
  с номером заявки.
- **Напоминания / рассылка по времени** — админ пишет
  `/broadcast 18:30 Текст`, бот отправляет сообщение всем известным
  пользователям в указанное время. `/jobs` — список запланированных.
- **Команды** — /start, /help, /lead, /cancel; админские /broadcast, /jobs
  видны только админу.

## Запуск

```bash
pip install -r requirements.txt
# в config.py вписать BOT_TOKEN и ADMIN_ID
python bot.py
```

`ADMIN_ID` — числовой id администратора, узнать через @userinfobot.

## Проверено

`demo_run.py` прогоняет логику без Telegram: умные ответы, полный цикл
заявки с записью и чтением, шаблон уведомления админу, список
получателей рассылки, валидация телефона. Все проверки проходят.

Боевой прогон в Telegram — нужен токен заказчика: код боевой части
стандартный aiogram-polling, ничего хитрого.
